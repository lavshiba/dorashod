========================================
12. короткие статусы и словарь
========================================

использовать именно так:
- запись добавлена
- запись обновлена
- запись удалена
- файл загружен
- файл готов
- импорт завершён
- категория скрыта
- подкатегория скрыта
- настройки сброшены
- валюта изменена
- время изменено

словарь:
- операции
- запись / записи
- изменить
- удалить
- скрыть
- вернуть
- сохранить в файл
- загрузить из файла
- все записи
- от всех расходов
- от всех доходов
- внутри категории

не использовать:
- редактировать
- править
- восстановить
- экспортировать
- импортировать
- операции категории
- операции подкатегории
- доля периода
- доля категории
