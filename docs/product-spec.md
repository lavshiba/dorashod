# Product Spec

## Назначение

`финансы` — Telegram-бот для личного учёта доходов и расходов. Пользователь работает только через Telegram: добавляет записи, ищет их, смотрит отчёты, управляет категориями и переносит данные через файлы.

## Source Of Truth По Текстам

Единственный frozen source of truth по экранным текстам, кнопкам, словарю и навигации:

- [`docs/frozen/ui-texts.txt`](frozen/ui-texts.txt)

Этот repo-local файл приоритетнее любых старых заметок и описаний в коде.

## Продуктовые Сценарии

### Onboarding

- 7 экранов с прогрессом `● ○ ○ ○ ○ ○ ○`;
- экран 7 ведёт либо в импорт данных, либо на главную;
- после пропуска onboarding пользователь может начать с первой записи или вернуться на главную.

### Главная

Пустое состояние:

- показывает, что записей пока нет;
- предлагает `доход`, `расход`, `операции`, `отчёт`, `категории`, `настройки`, `как пользоваться`.

Рабочее состояние:

- показывает блок `сегодня`;
- показывает блок `месяц`;
- показывает `последняя запись`;
- может дополнительно показывать `черновик` и `новые записи: n`.

### Добавление записей

Входы:

- кнопками `доход` и `расход`;
- одной строкой текста;
- несколькими строками текста;
- через исправление проблемной строки импорта.

Правила:

- если запись понята полностью, она сохраняется сразу;
- если не хватает полей, бот спрашивает только недостающее;
- пачка записей уходит в `новые записи`;
- у пользователя может быть один `черновик`.

### Черновик И Новые Записи

- `черновик` хранит незавершённый пошаговый ввод;
- `новые записи` держат очередь строк, которые нужно сохранить, исправить или пропустить;
- проблемная строка импорта проходит через отдельный экран исправления.

### Операции, поиск, отчёты

- `операции` показывают список записей с пагинацией;
- карточка записи открывается из списков и даёт `изменить` и `удалить`;
- `изменить запись` поддерживает правку полей записи;
- поиск поддерживает текстовый запрос и быстрые периоды;
- результаты поиска используют отдельный экран выдачи;
- отчёты поддерживают быстрые периоды и `свой период`;
- из списков можно открывать карточку записи;
- массовые действия работают из операций, поиска и отчётных списков.

### Категории и подкатегории

- отдельные ветки для доходов и расходов;
- создание, переименование, скрытие, возврат и удаление;
- перенос всех записей из категории или подкатегории;
- скрытые сущности показываются отдельными списками.

### Настройки

- валюта;
- время;
- включение и выключение подкатегорий;
- быстрый доступ;
- сортировка;
- повторный запуск onboarding из `как пользоваться`.

### Данные

`для этого бота`:

- экспорт полной копии в JSON;
- импорт полной копии с preview и подтверждением;
- замена текущих данных.

`в другие приложения`:

- экспорт реального CSV;
- импорт CSV и JSON с preview;
- импорт CSV терпим к русским и английским шапкам, `null` и `(null)`, decimal comma/dot, дате без времени и datetime с секундами;
- preview честно показывает, сколько строк прочитано, сколько валидных и какие обязательные колонки не распознаны;
- режимы `объединить` и `добавить всё`;
- исправление проблемных строк;
- `сбросить настройки`;
- `очистить всё`.

## Single-Screen И Inline-First

- бот должен по умолчанию переиспользовать один основной экран через inline keyboard;
- если экран можно отредактировать через `editMessageText`, нужно редактировать его, а не плодить новые сообщения;
- `screenMessageId` должен сохраняться в `ui_sessions` и переживать переходы между сценариями;
- удаление устаревших экранов и входящих сообщений считается частью ожидаемого поведения.

## Формат CSV Для `В Другие Приложения`

Экспорт и импорт используют колонки:

- `date`
- `time`
- `amount`
- `type`
- `category`
- `subcategory`
- `description`

Экспортный файл должен быть CSV и называться как CSV. Импорт этого же файла обратно в бота должен работать без ручного преобразования.
