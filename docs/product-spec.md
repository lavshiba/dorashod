# Product Spec

Этот документ хранит актуальную продуктовую логику Telegram-бота `финансы`.

Основной внешний source of truth по пользовательским текстам интерфейса:

- `/home/abihsgelo/.var/app/org.telegram.desktop/data/TelegramDesktop/tdata/temp_data/codex_ui_texts_package/frozen_ui_texts_for_codex.txt`

Если тексты в этом документе, коде или старых заметках расходятся с этим файлом, приоритет у файла.

На текущий момент под этот внешний frozen-файл уже заметно приведены:

- onboarding
- главная
- `новая запись`
- `черновик`
- `новые записи`
- `операции`
- карточка записи
- `изменить запись`

Дополнительное фактическое поведение:

- последний экран onboarding с кнопкой `перенести данные` теперь ведёт сразу в ветку загрузки файла с записями из другого приложения

## Замороженный словарь

Раздел:

- `операции`

Сущность:

- `запись`
- `записи`

Действия:

- `сохранить`
- `изменить`
- `удалить`
- `скрыть`
- `вернуть`
- `сохранить в файл`
- `загрузить из файла`

Запрещённые плавающие альтернативы:

- `редактировать`
- `править`
- `восстановить`
- `импортировать`
- `экспортировать`

Для отчётов использовать только:

- `записей`
- `все записи`
- `от всех расходов`
- `от всех доходов`
- `внутри категории`

## Правило неизменности пользовательских текстов

Тексты из ТЗ считаются замороженными. Любые расхождения между кодом и ТЗ решаются в пользу ТЗ, если только пользователь явно не согласовал новую формулировку.

## Onboarding

- Заголовок каждого экрана: `финансы`
- Прогресс: строка кружков без `1/7`
- Экран 1: `[начать]` и отдельной строкой `[пропустить]`
- Экраны 2-6: `[назад] [дальше]` и отдельной строкой `[пропустить]`
- Экран 7: `[назад] [перенести данные]` и отдельной строкой `[на главную]`
- После `[пропустить]` показывать:
  - `можно начать с первой записи`
  - `или сначала просто осмотреться`
  - кнопки `[доход]`, `[расход]`, `[на главную]`

Тексты экранов onboarding берутся из внешнего frozen-файла и сейчас уже отличаются от более ранней версии ТЗ.

1. Бот помогает вести доходы и расходы, искать старые записи, смотреть отчёты и переносить записи из других приложений.
2. Добавлять можно по шагам кнопками или одним сообщением.
3. Примеры:
   - `-450 продукты пятёрочка хлеб`
   - `+4000 зарплата премия`
   - `-120 транспорт метро`
4. Если бот понял запись не до конца, он сам уточнит только недостающее.
5. Любую запись потом можно найти, исправить, перенести в другую категорию или удалить.
6. Есть поиск, отчёты, категории и подкатегории.
7. Если записи уже есть в другом приложении, их можно перенести сюда; если нет — можно просто пойти дальше.

## Главная

### Если записей 0

Текст:

- `пока записей нет`
- можно добавить доход или расход кнопками
- или просто написать запись сообщением
- пример: `-450 продукты пятёрочка хлеб`

Кнопки:

- `[доход] [расход]`
- `[операции] [отчёт]`
- `[категории] [настройки]`
- `[как пользоваться]`

### Если записи уже есть

Показывать:

- блок `сегодня`: доход / расход
- блок `месяц`: доход / расход / баланс
- блок `последняя запись`: только сумма + категория + подкатегория

Кнопки:

- `[доход] [расход]`
- `[операции] [отчёт]`
- `[категории] [настройки]`
- по факту: `[черновик]`
- по факту: `[новые записи: n]`

## Добавление записей

Входы:

- `[доход]` / `[расход]` с главной
- обычное сообщение текстом
- пачка новых сообщений
- исправление неполной строки из импорта

Принципы:

- если всё понятно — сохранять сразу
- если чего-то не хватает — спрашивать только недостающее
- если записей несколько — отправлять в `новые записи`
- может существовать один активный `черновик`

Пошаговое добавление:

- спросить сумму
- потом категорию
- если нужно, подкатегорию
- потом необязательное описание с кнопкой `[пропустить]`
- дата и время по умолчанию = текущие

После сохранения: `запись добавлена`

## Черновик

Экран:

- краткое содержимое
- `[продолжить]`
- `[удалить]`
- `[главная]`

Удаление черновика: только через подтверждение.

## Новые записи

Кнопка на главной: `[новые записи: n]`

Поведение:

- разбор по одной записи
- если всё готово: `[сохранить] [изменить] [пропустить] [главная]`
- если чего-то не хватает: показать недостающее и вести к заполнению
- `[пропустить]` не удаляет запись

## Операции

- Список всех записей от новых к старым
- 6 записей на страницу
- В строке: сумма, категория, подкатегория если есть, дата и время
- Описание в списке не показывать

Кнопки:

- `[выбрать несколько]`
- `[поиск]`
- `[главная]`

Карточка записи:

- сумма
- категория/подкатегория
- описание, если есть
- дата и время

Кнопки:

- `[изменить]`
- `[удалить]`
- `[◀️] [▶️]`
- `[назад] [главная]`

Если время было поставлено автоматически, писать:

- `время поставлено автоматически`
- можно дать `[изменить время]`

## Поиск

Входной экран:

- `[ввести запрос]`
- `[сегодня] [вчера]`
- `[неделя] [месяц]`
- `[назад] [главная]`

После `[ввести запрос]`:

- бот ждёт запрос сообщением
- `[отмена]`
- `[главная]`

Если в режиме поиска приходит явная новая запись:

- спросить: `[искать это] [в новые записи]`

Если приходит пачка новых записей:

- автоматически отправить в `новые записи`

Результаты:

- сверху запрос
- сверху найдено
- 6 результатов на страницу
- `[выбрать несколько]`
- `[новый поиск]`
- `[назад] [главная]`

Из карточки записи, открытой из поиска:

- вместо `[назад]` использовать `[к результатам]`

## Массовые действия

Одинаково работают в:

- операциях
- поиске
- списках записей отчётов
- списках записей категории
- списках записей подкатегории

Экран действий:

- `[перенести]`
- `[удалить]`
- `[снять подкатегорию]`
- `[отмена]`
- `[главная]`

Если у выбранных записей нет подкатегорий, `[снять подкатегорию]` не показывать.

- `[год] [всё время]`
- `[свой период]`
- `[назад] [главная]`

- доход
- расход

Кнопки:

- `[по расходам]`
- `[по доходам]`
- `[все записи]`
- `[другой период]`
- `[назад] [главная]`

## Категории

Главный экран:

- `[расходы]`
- `[доходы]`
- `[назад] [главная]`

Список категорий:

- 6 на страницу
- `[+ категория]`
- `[скрытые]` только если скрытые реально есть

Карточка категории:

- тип
- записей
- подкатегории сразу внутри
- `[+ подкатегория]`
- `[изменить]`
- `[скрыть]`
- `[удалить]`
- `[все записи]`
- `[назад] [главная]`

У скрытой сущности вместо `[скрыть]` показывать `[вернуть]`.

- `[₽ рубль]`

- `[другая]`

Экран показывает:

- `включены` / `выключены`

- `[быстрый доступ]`
- `[сортировка]`

## Данные

Главный экран:

- `[для этого бота]`
- `[в другие приложения]`
- `[сбросить настройки]`
- `[очистить всё]`
- `[назад] [главная]`

### Для этого бота

- `[сохранить в файл]`
- `[загрузить из файла]`

### В другие приложения

- `[сохранить в файл]`
- `[загрузить из файла]`

После загрузки файла:

- `[объединить]`
- `[добавить всё]`
- `[назад] [главная]`

В этой ветке не использовать `[заменить]`.

## Общая навигация

Базовые кнопки:

- `[назад]`
- `[отмена]`
- `[главная]`

Значения фиксированы:

- `назад` = шаг назад в текущем сценарии
- `отмена` = бросить текущий сценарий целиком
- `главная` = выйти на главный экран

Если обычное `[назад]` двусмысленно, использовать честную кнопку по смыслу. Пример: `[к результатам]`.

## Пустые состояния

Пустой экран всегда должен говорить:

1. Чего пока нет.
2. Что можно сделать дальше.
